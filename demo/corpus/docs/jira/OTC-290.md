# OTC-290 Order API v2: cursor pagination for list endpoints

**Type:** Story · **Priority:** High · **Status:** Done · **Assignee:** priya

## Description

Implement cursor pagination for `GET /v2/orders` and `GET /v2/stores/{id}/orders` as specified in the [Order API v2 design](../notion/order-api-v2-design). The cursor encodes `(created_at, id)` and is base64url opaque to clients.

## Acceptance criteria

- `limit` between 1 and 100, default 20; invalid values return `400 INVALID_LIMIT`.
- `nextCursor` is null on the last page.
- Inserting new orders while paging never returns duplicates or skips rows.
