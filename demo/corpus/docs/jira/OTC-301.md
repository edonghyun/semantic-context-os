# OTC-301 상품 쿠폰 두 장 선택 시 할인이 두 번 차감됨

**유형:** Bug · **우선순위:** High · **상태:** Done · **담당:** jiwoo

## 설명

장바구니에서 상품 쿠폰 두 장을 고르면 두 쿠폰 할인액이 모두 차감된다. [쿠폰 정책](../notion/coupon-policy)상 상품 쿠폰끼리는 중복 적용할 수 없고 할인액이 큰 쪽만 적용해야 한다.

## 재현

1. 10% 상품 쿠폰과 3,000원 상품 쿠폰을 보유한 계정으로 로그인
2. 3만 원 상품을 담고 두 쿠폰을 모두 선택
3. 결제 금액이 24,000원으로 표시됨(기대: 27,000원)

## 원인

쿠폰 검증이 서버가 아니라 앱에서만 이뤄졌다. 서버 계산기에 종류별 1장 제한을 추가했다. 3.5.0에서 수정.
