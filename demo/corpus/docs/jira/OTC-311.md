# OTC-311 결제 승인 재시도 시 원래 멱등 키를 재사용

**유형:** Bug · **우선순위:** Highest · **상태:** Done · **담당:** jaehoon

## 설명

9월 7일 결제 중복 승인 장애의 근본 원인([포스트모템](../notion/postmortem-2026-09-07-duplicate-charges)). payment-gateway의 capture 재시도가 새 `Idempotency-Key`를 만들어 Bramblepay가 재시도를 별개 승인으로 처리했다.

## 수정

- 멱등 키를 결제 id와 시도 그룹에서 결정적으로 만든다. 같은 capture의 재시도는 항상 같은 키를 쓴다.
- 재시도 경로 단위 테스트 추가: 첫 요청 타임아웃 → 재시도 요청의 키가 같은지 검증.
- `payments.capture-retry` 플래그는 3.4.0 배포 후 다시 켰다.
