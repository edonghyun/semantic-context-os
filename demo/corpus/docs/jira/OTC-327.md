# OTC-327 Flaky checkout end-to-end test on CI

**Type:** Bug · **Priority:** Medium · **Status:** In Progress · **Assignee:** jiwoo

## Description

`CheckoutFlowE2ETest.paysWithSavedCard` fails about 1 in 12 runs on CI with a timeout waiting for the order confirmation screen. It never fails locally.

## Findings

- The fake Bramblepay server in CI starts after the app container in some runs; the first authorise call hits a closed port and the client backs off for 10 s.
- Fix: add a readiness check for the fake Bramblepay before starting the app; remove the fixed `sleep 5` in the CI script.

## Comments

- jiwoo (10-01): Readiness check merged; 200 CI runs without a failure so far.
