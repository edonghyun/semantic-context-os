# OTC-340 APNs token refresh blocks the notify queue consumers

**Type:** Bug · **Priority:** Highest · **Status:** Done · **Assignee:** kevin

## Description

Root cause of the [2026-10-02 push delay](../notion/postmortem-2026-10-02-push-delay). The APNs auth token refresh runs on the consumer thread; when the token endpoint times out (30 s), all consumers stall and `notify.ios` backs up.

## Fix

- Refresh the token on a background scheduler every 45 minutes; keep using the old token until the new one is ready.
- 3 s timeout on all APNs calls.
- Apply the same change to the SMS sender, which refreshes its provider token the same way.

## Comments

- kevin (10-04): Deployed; forced token endpoint timeouts in staging no longer delay delivery.
