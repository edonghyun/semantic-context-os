# OTC-352 Android app crashes at checkout when the address list is empty

**Type:** Bug · **Priority:** High · **Status:** Done · **Assignee:** jiwoo

## Description

New users who skip address entry during sign-up crash on the checkout screen: `IndexOutOfBoundsException` in `AddressSelector.defaultAddress()` when the saved address list is empty. Crash rate 0.8% of Android checkout sessions on 3.3.2.

## Fix

Show the "add address" form when the list is empty instead of selecting index 0. Added a UI test for a user with no saved addresses. Shipped in 3.4.0.
