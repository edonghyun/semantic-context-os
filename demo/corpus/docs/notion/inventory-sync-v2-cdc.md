# 재고 동기화 v2: CDC 기반 설계

## 배경

지금 inventory-sync는 15분마다 매장 POS의 재고 전체를 폴링한다. 재고가 화면에 늦게 반영돼 품절 상품 주문이 하루 평균 230건 생기고, 그중 대부분이 주문 취소로 이어진다. 8월 말 폴링 배치가 밀리면서 지연이 40분까지 늘었다.

## 제안

매장 POS 연동 서버가 재고 변경 이벤트를 내보내게 하고(CDC), inventory-sync는 이벤트를 구독해 변경분만 반영한다. 목표 지연은 1분 이내.

- 이벤트: `stock.changed {storeId, sku, quantity, version}` — `version`이 낮은 이벤트는 버린다.
- 전체 폴링은 하루 한 번 대사(reconciliation)용으로만 남긴다.
- 이벤트 유실 대비: 매장별 마지막 version을 저장하고, 끊김이 감지되면 그 매장만 전체 동기화한다.

## 단계

1. POS 연동 서버 2곳(파일럿 매장 12개)에서 이벤트 발행
2. 그림자 모드로 기존 폴링 결과와 비교
3. 전 매장 전환, 폴링 주기를 15분 → 24시간으로
