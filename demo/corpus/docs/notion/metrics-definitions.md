# 핵심 지표 정의

## 주문 전환율

**주문 전환율 = 결제 완료 주문 수 / 장바구니에 상품을 담은 세션 수.** 같은 세션의 여러 주문은 1건으로 센다. 9월 1일부터 분모를 "앱 방문 세션"에서 "장바구니 담은 세션"으로 바꿨다 — 이전 대시보드와 직접 비교하지 않는다([OTC-360](../jira/OTC-360)).

## 배송 소요 시간

결제 완료 시각부터 배달 완료 시각까지. 중앙값과 p90을 함께 본다. 고객이 고른 배송 시간대 주문은 제외한다.

## 지각 배송률

배송 소요 시간이 45분을 넘은 주문의 비율.

## 품절 취소율

품절 때문에 취소된 주문 / 전체 주문.
