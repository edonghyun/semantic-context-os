# 포스트모템: 2026-09-07 결제 중복 승인 (SEV1)

## 요약

2026-09-07 02:10~03:05(KST) 사이 일부 주문에서 카드 결제가 두 번 승인됐다. 영향 주문 412건, 고객 397명, 중복 승인 금액 합계 약 1,180만 원. 전액 환불은 9월 9일에 끝났다([OTC-318](../jira/OTC-318)).

## 타임라인

- 02:10 payment-gateway 배포 3.4.0-hotfix1 완료
- 02:14 Bramblepay 승인 API 응답 지연(p99 9초) 시작
- 02:20 CS 채널에 "두 번 결제됐다" 문의 첫 접수
- 02:41 온콜(minji) 페이지 수신, SEV2 선언
- 02:52 중복 승인 확인, SEV1로 상향, 재시도 기능 플래그 `payments.capture-retry` 끔
- 03:05 신규 중복 승인 0건 확인

## 근본 원인

payment-gateway는 Bramblepay 승인 요청이 5초 안에 응답하지 않으면 한 번 재시도한다. 핫픽스에서 재시도 경로가 **멱등 키(Idempotency-Key) 헤더를 새로 생성**하도록 바뀌었다. Bramblepay는 첫 요청을 늦게나마 처리했고, 재시도는 다른 키라 별개 승인으로 처리됐다. 리뷰에서 재시도 경로 테스트가 없었다.

## 잘한 점 / 아쉬운 점

- 잘한 점: 기능 플래그로 15분 안에 재시도를 끌 수 있었다.
- 아쉬운 점: 중복 승인 알림이 없어 CS 문의로 처음 알았다. 온콜 페이지까지 31분이 걸렸다.
