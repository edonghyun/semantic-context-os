# 릴리스 노트 3.5.0 (2026-10-14)

## 고객 앱

- 배송 시간대 선택: 주문 시 2시간 단위 배송 시간대를 고를 수 있다(서울 일부 지역, [OTC-350](../jira/OTC-350)).
- 쿠폰을 두 장 이상 적용할 때 할인 금액이 두 번 차감되던 버그 수정([OTC-301](../jira/OTC-301)).

## 알림

- iOS 푸시 지연 재발 방지: APNs 토큰 갱신을 백그라운드로 옮겼다([OTC-340](../jira/OTC-340)).
- notify 큐 적체 알림 추가([OTC-341](../jira/OTC-341)).

## 플랫폼

- PostgreSQL 17 업그레이드 완료([OTC-288](../jira/OTC-288)).
- 오래된 기능 플래그 14개 제거([OTC-355](../jira/OTC-355)).

## 알려진 문제

- 일부 매장의 재고 반영이 최대 10분 늦을 수 있다. 재고 동기화 v2(CDC) 작업 중([OTC-275](../jira/OTC-275)).
