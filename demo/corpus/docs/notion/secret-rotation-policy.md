# 시크릿 교체 정책

## 주기

- 결제 대행사(Bramblepay) API 키: 90일마다 교체. 교체 기간에는 신·구 키를 24시간 동시에 허용한다.
- 데이터베이스 비밀번호: 180일마다.
- 개인 액세스 토큰: 만료 30일 이하로만 발급.

## 절차

1. 보안 담당이 교체 티켓을 만든다(예: [OTC-333](../jira/OTC-333)).
2. 새 키를 시크릿 저장소에 넣고, 서비스는 재배포 없이 5분 안에 읽어 간다.
3. 24시간 뒤 구 키를 폐기하고 감사 로그를 티켓에 첨부한다.

## 금지

시크릿을 Slack, 이슈, 코드에 붙여 넣지 않는다. 실수로 노출하면 즉시 `#security`에 알리고 바로 교체한다.
